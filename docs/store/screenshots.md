# Store graphics

## Feature graphic
`assets/store/feature-graphic.png` (1024 x 500 PNG, no transparency, as Play requires).

## Phone screenshots (2 to 8 needed, put them in assets/store/phone)
Take them on the release build, 1080 x 1920 or similar portrait, no device frame.
Suggested order and file names:

1. `01-welcome.png` Welcome / sign in
2. `02-home.png` Home with trips
3. `03-itinerary.png` Itinerary day view
4. `04-explore.png` Explore nearby places
5. `05-flight-status.png` Flight status
6. `06-currency.png` Currency converter or weather
7. `07-profile-dark.png` Profile with dark mode on
8. `08-offline.png` Offline banner or synced trip

Tip: use demo data with a real looking trip (no personal details), same device and battery/clock for all shots.
